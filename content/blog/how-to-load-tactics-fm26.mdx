## How to Load Tactics in FM26

You've found a great tactic online, downloaded the .fmf file — now what? Loading tactics in FM26 is straightforward once you know the right folder and menu. Here's the complete guide.

<Callout type="tip" title="TL;DR — Three Quick Ways to Load Tactics in FM26">

1. **In-game menu**: Tactics screen → dropdown → **Load Tactic** → browse to the .fmf file
2. **Copy to tactics folder**: Windows `Documents\Sports Interactive\Football Manager 2026\tactics\` (Mac & Xbox paths in the guide below)
3. **Steam Workshop**: Tactics screen → dropdown → **Manage Tactics...** → Steam Workshop → **Subscribe**

</Callout>

---

## Method 1: Load Tactics via the In-Game Menu (Recommended)

This is the easiest way — no file management needed:

1. **Open the Tactics Screen** — Click the Tactics tab in the left sidebar (or press `Ctrl+T` / `Cmd+T`)
2. **Tactics Dropdown** — Click the dropdown next to your current tactic name in the top-left
3. **Load Tactic** — Select **"Load Tactic"** from the dropdown menu
4. **Browse** — Navigate to where you saved the .fmf file and select it
5. **Apply** — The tactic loads into one of your three tactic slots

> Note: You can store thousands of tactics — the game only loads them when you load a save.

---

## Method 2: Copy the .fmf File to the Tactics Folder

If you want the tactic to appear in the in-game browser automatically:

### Windows
```
Documents\Sports Interactive\Football Manager 2026\tactics\
```

### Mac
```
~/Library/Application Support/Sports Interactive/Football Manager 2026/tactics/
```

(The Library folder is hidden by default — in Finder, press `Cmd+Shift+G` and paste the path)

### Xbox / Microsoft Store / Game Pass
```
%LOCALAPPDATA%\Sports Interactive\Football Manager 2026\tactics\
```

1. **Extract** the .fmf file from any downloaded zip/rar archive
2. **Copy** the .fmf file into the `tactics` folder above
3. **In-game** → Tactics → Load Tactic — your file will appear immediately

---

## Method 3: Steam Workshop Subscription

Best for keeping up with updates from tactic creators:

1. **In-game** → Tactics screen → Dropdown → **"Manage Tactics..."**
2. Click **"Steam Workshop"** tab
3. Browse or search for tactics
4. **Subscribe** — the tactic auto-downloads and stays updated
5. Load it from your tactics dropdown like normal

> Pro tip: Only subscribe to tactics with recent updates (2026 patch). Older tactics may not work optimally with the current match engine.

---

## Method 4: Importing from FM25 or Older Versions

FM26 can import `.fmf` files from Football Manager 2025 and FM 2024. However:

- Player roles and instructions may differ — review them after import
- Team instructions should be re-saved to trigger FM26's tactical familiarity system
- Set piece routines need to be re-setup (the FM26 set piece creator is different)

### Steps:
1. Copy your old `.fmf` to the FM26 tactics folder
2. Load it via the in-game menu
3. **Re-save** the tactic in FM26 format (Save → rename → save as new .fmf)
4. Double-check all player roles and team instructions

## Common Loading Issues (and Fixes)

| Problem | Solution |
|---|---|
| Tactic not showing in dropdown | Make sure it's in the correct `tactics/` folder, not a subfolder |

## Understanding Tactics Once You've Loaded Them

After loading a tactic, spend 5 minutes understanding it before your next match:

1. **Check Team Mentality** — Is it attacking, balanced, or defensive? This determines everything
2. **Review Player Roles** — Red/orange dots mean a player doesn't fit the role. Green = natural
3. **Look at Team Instructions** — In Possession, In Transition, Out of Possession
4. **Note Key Player Requirements** — If the tactic requires "Pace 16+ CBs", make sure you have them
5. **Train Tactical Familiarity** — Use Match Practice + Tactical training in pre-season
